# 🤝 Contributing Guide

Danke für dein Interesse an Bitcoin-Toshi! Hier erfährst du, wie du beitragen kannst.

## Arten von Beiträgen

### 📝 Content
- Neue Lektionen vorschlagen
- Texte korrigieren/verbessern
- Übersetzungen

### 🎨 Design
- Character-Varianten
- Hintergrund-Designs
- UI-Elemente

### 💻 Code
- Bug Fixes
- Neue Features
- Dokumentation

### 🧪 Testing
- Content auf Verständlichkeit prüfen
- App testen
- Feedback geben

## Getting Started

1. **Fork** das Repository
2. **Clone** deinen Fork
3. Erstelle einen **Branch** für deine Änderung
4. Mache deine Änderungen
5. **Commit** mit aussagekräftiger Message
6. **Push** zu deinem Fork
7. Erstelle einen **Pull Request**

## Commit Messages

Format: `[Bereich] Kurze Beschreibung`

Beispiele:
```
[Content] Woche 2 Tag 3 hinzugefügt
[Design] Toshi running animation
[Docs] ARCHITECTURE.md aktualisiert
[Fix] Typo in Woche 1 behoben
```

## Style Guidelines

### Content
- Siehe `docs/STYLE_GUIDE.md`
- Deutsch als Hauptsprache
- JRPG-Dialog-Stil einhalten
- Max. 3 Zeilen pro Dialog-Box

### Code
- Python: PEP 8
- Swift: Apple Style Guide
- Kommentare auf Deutsch oder Englisch

### Design
- Pixel-Art Spezifikationen beachten
- Farbpalette einhalten
- Exportieren als PNG (transparent)

## Pull Request Checkliste

- [ ] Branch ist aktuell mit `main`
- [ ] Änderungen getestet
- [ ] Style Guide eingehalten
- [ ] Dokumentation aktualisiert (wenn nötig)
- [ ] Screenshots/Beispiele beigefügt (wenn relevant)
